Filament Care C3

Gravação direta via USB pelo navegador, configuração instantânea de Wi-Fi e controle completo de rampas térmicas para secagem de PLA, PETG, ASA e ABS.

Fluxo de Funcionamento

1
Flash via USB
Transfere o firmware compilado direto para o ESP32-C3.
2
Injeção de Wi-Fi
Envia SSID e senha via WebSerial para a memória NVS da placa.
3
Acesso pelo IP Local
O ESP32-C3 exibe o IP no OLED e hospeda o painel das rampas.

Instalação Direta no ESP32-C3

1
Gravar Firmware na Placa (WebSerial)

Conecte seu ESP32-C3 na porta USB (use Chrome ou Edge). Clique no botão abaixo para transferir o sistema completo.

Seu navegador não suporta WebSerial. Use Google Chrome ou Microsoft Edge no PC. Este site precisa ser aberto via HTTPS ou localhost para acessar a porta USB.
2
Configurar Wi-Fi no ESP32-C3

Após gravar o firmware, envie sua rede diretamente para a placa. Ela salvará na memória interna, reiniciará e exibirá o IP no OLED.
