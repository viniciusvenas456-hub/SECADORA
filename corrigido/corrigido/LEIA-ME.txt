COMO USAR (3 arquivos para trocar no repositório SECADORA)

1) SECADORA/SECADORA.ino  -> abra no Arduino IDE (substitui o seu sketch)
2) index.html             -> substitui o do repositório
3) manifest.json          -> igual ao seu (só version 1.0.1); pode manter o antigo

GERAR O firmware.bin CORRETO (esta é a causa da tela apagada):
  Arduino IDE > Ferramentas:
    Placa: ESP32C3 Dev Module
    USB CDC On Boot: Enabled
    Partition Scheme: Default 4MB with spiffs
  Sketch > Exportar Binário Compilado
  Na pasta "build/esp32.esp32.esp32c3" do sketch use o arquivo
      SECADORA.ino.merged.bin
  NÃO use SECADORA.ino.bin (só o programa; não liga a placa em offset 0).
  Renomeie o merged para firmware.bin e suba no repositório, na mesma pasta do index.html.

Bibliotecas: U8g2, Adafruit BME280 Library, Adafruit Unified Sensor, OneWire, DallasTemperature.

Teste: após gravar, o LED azul deve acender e o OLED mostrar "Filament Care C3".
